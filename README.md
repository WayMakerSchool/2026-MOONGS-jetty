# 🚀 프로젝트 이름

> 한 줄로 프로젝트를 소개해 주세요.

압력 및 움직임 센서와 AI를 활용해 발목의 회복 상태를 분석하고, 개인 맞춤형 재활 가이드를 제공하는 스마트 재활 시스템입니다.

<br>

## 📖 프로젝트 소개

- **기간**: 2026.00.00 ~ 2026.00.00
- **프로젝트**: 코드페어
- **소개**: 발목 부상 환자는 깁스나 보호대를 착용해도 **현재 얼마나 회복되었는지 객관적으로 확인하기 어렵습니다.** 뭉스는 이러한 불편을 해결하기 위해, 발목 부상 후 재활 중인 사용자의 **압력과 움직임 데이터를 측정·분석하여 회복 상태를 확인하고 개인 맞춤형 재활 가이드를 제공하는 서비스**입니다.

<br>

## ✨ 주요 기능

| 기능 | 설명 |
| :-- | :-- |
| 실시간 보행 분석 | 압력 및 움직임 센서 데이터를 활용해 발목의 하중과 보행 상태를 분석합니다. |
| AI 맞춤형 재활 가이드 | 누적된 데이터를 분석해 개인의 회복 상태와 위험 신호에 맞는 재활 가이드를 제공합니다. |

<br>
